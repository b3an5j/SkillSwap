# Skills Swap

**Trade Skills. Not Money.**  
SkillSwap lets you exchange your abilities with others.
Build connections, learn new things, and help others.

## Overview

A tool for looking for people with soft skills that you might need or interested in. You can pair up to find a suitable person to match up with, and then exchange your skills. </p>

## Stack

- **Python (Flask)** — routing, sessions, server logic
- **SQLite** — lightweight relational database
- **Tailwind CSS** — utility‑first styling

Setup

1. Setup virtual environment:

```bash
python -m venv .venv
```

2. Activate virtual environment:  
   Mac / Linux

```bash
source .venv/bin/activate
```

Windows

```bash
.\venv\Scripts\Activate.ps1     # powershell
.\venv\Scripts\activate.bat     # cmd
source venv/Scripts/activate    # git bash
```

3. Install requirements

```bash
pip install -r requirements.txt
```

4. Launch Flask app
   Run the `app.py`  
   or run:

```bash
flask run
```
